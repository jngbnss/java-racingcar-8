중복이랑 특수문자

> AngularJS Commit Message Conventions을 따른다.

| 타입           | 설명                 |
|--------------|--------------------|
| **feat**     | 새로운 기능 추가          |
| **fix**      | 버그 수정              |
| **refactor** | 코드 리팩터링            |
| **style**    | 포맷, 세미콜론 등 비기능적 변경 |
| **test**     | 테스트 코드 추가          |
| **docs**     | 문서 수정              |
| **chore**    | 설정, 빌드 관련 변경       |
