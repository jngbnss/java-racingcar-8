기능 요구 사항
1. 주어진 횟수 동안 n대의 자동차 전진 또는 정지
2. 자동차에 이름 부여, 출력 시 이름 같이 출력
3. 쉼표 기준 구분, 5자 이하
4. 몇 번의 이동 할 것 인지 입력
5. 0~9 랜덤 4이상 전진
6. 우승자 발표 1명이상 가능
7. 여러명 쉼표 구분
8. 예외처리

입출력 요구사항 
1. 쉼표 구분
2. 차수별 실행 결과 출력
3. 우승자 안내 문구 쉼표

## 🧩 커밋 컨벤션

> AngularJS Commit Message Conventions을 따른다.

| 타입           | 설명                 |
|--------------|--------------------|
| **feat**     | 새로운 기능 추가          |
| **fix**      | 버그 수정              |
| **refactor** | 코드 리팩터링            |
| **style**    | 포맷, 세미콜론 등 비기능적 변경 |
| **test**     | 테스트 코드 추가          |

| **chore**    | 설정, 빌드 관련 변경       |
